HOW ALPHAFOLD
PREDICTS PROTEIN STRUCTURE
AlphaFold 3 solved one of biology's hardest problems — predicting how an amino acid sequence folds into a 3D protein. The system achieves lab-quality accuracy in minutes vs. years of X-ray crystallography. Understanding the cycle reveals why it's one of AI's most significant scientific breakthroughs.

Engine
01
Amino Acid Sequence
Input: raw protein sequence (e.g. MKTIIALSYIFCLVFA…). Tokenized into residue representations. Up to 2,048 residues per pass in AF3.
Input Layer
02
Multiple Sequence Alignment
Query UniRef90 + BFD databases for evolutionary relatives. Coevolution signals in aligned columns reveal which residues interact — biological physics encoded in sequence history.
MSA Processing
03
Pair Representation
+ Evoformer Blocks
48 Evoformer blocks run row/column attention over MSA and pair features simultaneously. Learns spatial relationships between every residue pair — implicit 3D geometry emerges.
Core Architecture
04
Structure Module
+ 3D Coordinates
Invariant point attention (IPA) assigns rigid body frames to each residue. Iteratively refines backbone torsion angles → final (x,y,z) coordinates for every atom. Output: PDB format.
3D Prediction
05
Confidence Scoring
+ Validation
pLDDT score (0–100) per residue measures local accuracy. PAE matrix measures inter-domain accuracy. High-confidence regions (>90) match experimental structures within 1Å RMSD.
