# Actionable Framework Examples

Use these as templates for the "Application" card or `numbered-list` snippet in `case-study` infographics. Each framework distills a case study into a reproducible 4–5 step procedure.

---

## 1. Presale Validation Framework

**Tactic:** Sell before you build. Validate with buyer commitment, not survey interest.

**Steps:**
1. Identify a specific audience with a recurring pain (niche = less competition)
2. Build a waitlist landing page with clear LTD offer (price = 2–3× annual subscription)
3. Drive 200–500 targeted visitors via community posts (Reddit/Indie Hackers/X, no ads)
4. Close first 20–50 buyers manually via DM/Calendly — collect payment
5. Use collected revenue to fund MVP build; partner to accelerate (50% revenue bump)

**Search keywords:** "presell lifetime deals before building", "Indie Hackers presale validation", "LTD validation playbook"

## 2. Event-Based Pricing Pivot

**Tactic:** Align price to customer behavior, not traditional subscription tiers.

**Steps:**
1. Audit current usage patterns — are customers charging per event, not per seat?
2. If >60% of usage is event-driven, calculate event-to-subscription ratio (typical: subscription = 4–6× event price)
3. Design event-based pricing tier (volume discounts for 10+ events)
4. Keep subscription as secondary option to avoid alienating existing base
5. A/B test with 20 existing customers before full migration; monitor churn

**Search keywords:** "event-based pricing SaaS case study", "usage-based vs subscription pricing", "Stagetimer pricing experiment"

## 3. LLM Integration Quick-Sprint

**Tactic:** Use LLMs to automate high-friction workflows, measure impact with 30-day sprint.

**Steps:**
1. List all repetitive text/code/user communication tasks in your product
2. Pick one highest-friction workflow (onboarding emails, support replies, code suggestions)
3. Integrate GPT-4/Claude via API; maintain human review loop (no full autonomy)
4. Track time saved, satisfaction scores, churn impact pre- and post-integration
5. Budget $500–$1000 in API credits for 30-day sprint; if ROI positive, expand to next workflow

**Search keywords:** "Indie Hackers LLM integration case study", "B2B SaaS AI automation", "reducing churn with LLMs"

## 4. Growth Experiment Engine

**Tactic:** Treat growth as an engineering discipline with owned outcomes and automated data science.

**Steps:**
1. Hire 1 growth engineer per 3–4 product engineers; give outcome-based OKRs (signups, activation, revenue)
2. Equip team with Python + Claude Code + analytics DB read access
3. Generate 2–3 experiment ideas per week per engineer; run rigorous A/B tests
4. Automate experiment analysis with LLM data-science scripts (data cleaning, statistical significance)
5. Package successful patterns as reusable MCP/skills; accumulate to playbook (benchmark: 90 experiments/engineer/year)

**Search keywords:** "AI-native growth team framework", "growth engineer vs product engineer", "running 100 experiments per year"

## 5. AI Search (AEO) Template Optimization

**Tactic:** Optimize landing/template pages to appear in AI-generated answers, not just Google SERPs.

**Steps:**
1. Audit high-traffic landing/template pages — pick top 5 by impression volume
2. For each page, rewrite above-the-fold copy with 4-element AEO formula:
   a. Head question matching exact user query
   b. Branded money term (your product name)
   c. Specific target user segment
   d. Pain-point solution (your differentiator)
3. Create dedicated pages for long-tail "best [category] for [use case]" queries
4. Engage Reddit non-promotionally on relevant threads with value-first comments
5. Measure LLM signup traffic share and CVR (target: >20% CVR from AI vs <5% from Google)

**Search keywords:** "AEO copy formula head question brand user pain", "Webflow AI search optimization", "template page SEO 2026"

## 6. Speed-Based Validation Sprint

**Tactic:** Validate demand before coding with a mocked demo that books real calls.

**Steps:**
1. Pick one problem space per sprint (weekly/bi-weekly cadence)
2. Build a no-code mock demo (Figma, Notion, Carrd) showing core workflow
3. Share in relevant communities (Indie Hackers, niche Discord, Twitter/X)
4. Measure interest via Calendly bookings or waitlist signups — threshold: 20+ qualified calls in 2 weeks
5. If threshold hit, proceed to code; if not, pivot next sprint. Speed beats perfection.

**Search keywords:** "12 startups in 12 months framework", "validation with mock demo", "speed over perfection startup"

## 7. Bootstrapped Quality-First Growth

**Tactic:** Optimize for product quality and retention, not vanity metrics. Revenue compounds at 2–3 year lag.

**Steps:**
1. Niche down to a specific user segment; ignore broad market opportunity
2. Ship updates monthly, not weekly — deep work over reactive velocity
3. Source every support request into a public roadmap; let users vote
4. Prioritize bug fixes and polish features over new features
5. Track NPS and retention religiously; let metrics drive roadmap, not competitor moves

**Search keywords:** "bootstrapped SaaS quality over growth", "slow sustainable SaaS growth", "product quality compounding revenue"

## 8. Low-Budget Ad Validation

**Tactic:** Validate paid ads cheaply before scaling: outcome headlines > feature copy.

**Steps:**
1. Create 3 ad creatives with benefit-driven headlines (one-line outcome promise, not feature list)
2. Run $20/day on Twitter/LinkedIn for 5 days per creative (total budget $300)
3. Pause any creative with <5 signups in that window
4. Once total conversions hit 15+ (95% statistical confidence threshold), scale to $100–$200/day
5. Ensure landing page headline exactly matches ad promise; test new headline every 50 conversions

**Search keywords:** "Evil Martians validation playbook", "$2000 product validation framework", "A/B testing ad creatives before scaling"

## 9. Founder Brand → Launch Sequence

**Tactic:** Leverage open-source credibility and founder brand for exponential launch amplification.

**Steps:**
1. Build in public on GitHub for 6–12 months pre-monetization — aim for 10K+ stars solving real pain
2. Document journey weekly on Twitter/X; build audience of 5K+ engaged followers
3. Secure podcast/guest slots 30 days pre-launch; tease problems your product solves
4. Execute triple-channel launch day: Product Hunt + Hacker News + Twitter/X thread (coordinated)
5. Offer lifetime deals or heavy discounts in first week; convert early adopters to monthly after 30 days

**Search keywords:** "open source to Product Hunt launch strategy", "GitHub stars to revenue playbook", "founder brand building pre-launch"
